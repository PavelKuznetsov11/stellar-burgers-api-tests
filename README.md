# Stellar Burgers API Tests

Проект с API-автотестами для сервиса Stellar Burgers.

Цель проекта — проверить основные backend-сценарии приложения через REST API: регистрацию, авторизацию, изменение данных пользователя, создание заказов и получение информации о заказах.

## Что тестируется

- регистрация нового пользователя
- регистрация пользователя с некорректными данными
- авторизация пользователя
- изменение данных пользователя
- создание заказа
- создание заказа с авторизацией и без авторизации
- получение заказов пользователя
- обработка позитивных и негативных сценариев

## Технологии

- Python
- Pytest
- Requests
- Allure
- REST API
- JSON
- Git

## Что проверяют тесты

- HTTP-статус-коды
- структуру JSON-ответа
- обязательные поля в response body
- корректность сообщений об ошибках
- обработку некорректных данных
- сценарии с авторизацией и без авторизации
- работу API-эндпоинтов

Как запустить проект

Клонировать репозиторий:
git clone https://github.com/PavelKuznetsov11/stellar-burgers-api-tests.git

Перейти в папку проекта:
cd stellar-burgers-api-tests

Создать и активировать виртуальное окружение:
python -m venv venv

Для Windows:
venv\Scripts\activate

Для macOS / Linux:
source venv/bin/activate

Установить зависимости:
pip install -r requirements.txt

Запустить тесты:
pytest -v

Запустить тесты с генерацией Allure-результатов:
pytest --alluredir=allure_results

Открыть Allure-отчёт:
allure serve allure_results

Примеры проверок:
успешная регистрация пользователя
ошибка при регистрации без обязательного поля
успешная авторизация
ошибка при авторизации с неверными данными
изменение данных авторизованного пользователя
создание заказа с ингредиентами
получение заказов пользователя

Результат:
В проекте реализованы API-автотесты на Python с использованием Pytest и Requests.
Тесты покрывают позитивные и негативные сценарии, проверяют статус-коды, JSON-ответы и обработку ошибок backend-сервисом.
